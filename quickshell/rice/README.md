# Sairex Rice

NixOS + Quickshell desktop shell with a floating UI inspired by the design philosophy of Caelestia and ax-shell.

## Current stage

- Floating top bar
- Centralized shell state
- Floating Wi-Fi popup
- Floating audio popup
- PipeWire volume control
- Centralized theme
- Multi-monitor aware structure

## Development

```bash
qs -p /etc/nixos/quickshell/rice/shell.qml
```

## Roadmap

Wi-Fi integration, audio polish, Bluetooth, Matugen, launcher, dashboard, control center, notifications, MPRIS, OSD, performance and final NixOS integration.
